Install in 3 steps

AKC Shopping is not on the Play Store yet, so Android asks you to confirm the install. This is normal for apps downloaded outside the Play Store.

  1. Download the app

    Tap the Download button. If your browser warns about the file, choose Download anyway.

  2. Open the file

    If Android says your phone isn’t allowed to install unknown apps, tap Settings and turn on Allow from this source. Then go back.

  3. Install without scanning

    If Play Protect shows a warning, tap More details, then Install without scanning. Tap Install, then Open.
