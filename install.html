How to install AKC Shopping

This takes about 2 minutes and works on Android phones. Keep at least 150 MB of free space. AKC Shopping is not on the Play Store yet, so Android asks you to confirm a few things. This is normal for apps downloaded outside the Play Store.

  1. Download the app

    Tap Download for Android below. If your browser says “This type of file can harm your device”, tap OK or Download anyway. The file is called AKC-Shopping.apk (59.5 MB). Wait until the download finishes.

  2. Open the file

    Tap Open on the download notification, or open your Files or Downloads app and tap AKC-Shopping.apk.

  3. Allow installs from this source

    If Android says “For your security, your phone isn’t allowed to install unknown apps from this source”, tap Settings, turn on Allow from this source, then press the back button to return to the install screen.

  4. Install without scanning

    If Google Play Protect shows “App blocked” or “Scan app”, tap More details, then tap Install without scanning. On some phones the button is called Install anyway.

  5. Install and open

    Tap Install. When it finishes, tap Open, then sign up or log in and start shopping.

Good to know

Button names can look a little different on each phone brand. Choose the option that lets the install continue.

To update later, download the newest version from this site and install it over the old one.

If you see “App not installed”, delete any older or test copy of AKC Shopping from your phone, then try again.
